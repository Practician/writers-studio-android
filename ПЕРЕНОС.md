# Writer's Studio — запуск на другом ПК

Это чистая копия исходников с полной историей git (папка `.git` внутри).

## Что нужно на новом ПК

1. **Node.js** версии 20 или новее — https://nodejs.org

## Первый запуск

```bash
cd writers-studio-src
npm install
```

2. Создайте файл `.env` в корне проекта (по образцу `.env.example`) и впишите свой ключ:

```
GEMINI_API_KEY=ваш_ключ_из_Google_AI_Studio
```

Ключ бесплатно выдаётся на https://aistudio.google.com/apikey
(файл `.env` со старого ПК сюда сознательно не скопирован — секреты переносите отдельно).

Можно добавить резервные ключи — при исчерпании дневной квоты первого сервер
переключится на следующий автоматически:

```
GEMINI_API_KEY_2=резервный_ключ
GEMINI_API_KEY_3=ещё_один
```

Важно: резервные ключи должны быть из **разных проектов** Google AI Studio —
квота считается на проект, два ключа одного проекта делят одну общую квоту.

### NVIDIA NIM (опционально)

Ключ: https://build.nvidia.com/ → Get API Key (`nvapi-...`)

```
# .env — опционально (можно вводить ключи в UI: ⚙ в шапке)
GEMINI_API_KEY=...
NVIDIA_API_KEY=nvapi-...
GROQ_API_KEY=gsk_...
OPENROUTER_API_KEY=sk-or-...
LLM_PROVIDER=auto
```

**Ключи: UI или .env?**

| Способ | Плюсы | Минусы |
|--------|-------|--------|
| **⚙ в приложении** (localStorage) | Удобно, без правки файлов | Только этот браузер; XSS теоретически видит ключ |
| **`.env` на сервере** | Не в браузере, удобно для скриптов | Нужен перезапуск/редактор |

Рекомендация: **личный localhost** — UI ок; **общий сервер** — только `.env`. UI перекрывает `.env` на время запроса, если поле заполнено.

Провайдеры в шапке: **NVIDIA · Gemini · Groq · OR · Все** (auto: NVIDIA → Groq → OpenRouter → Gemini; Gemini с timeout 45 с и thinkingBudget=0).

**Ротация для русской прозы** (503 / timeout / 429 → cooldown + следующая; 404/410 → skip до рестарта):

| Tier | Модели | Заметка |
|------|--------|---------|
| A | `deepseek-v4-flash`, `deepseek-v4-pro`, `qwen3.5-122b`, `qwen3-next-80b`, `qwen3.5-397b`, `glm-5.2`, `minimax-m3/m2.7` | Лучший RU; часто заняты на free NIM |
| B | `mistral-medium-3.5-128b`, `mistral-small-4-119b`, `mistral-nemotron`, `ministral-14b`, `mistral-large-*` | Быстрые, стабильный русский |
| C | `llama-3.3-70b`, `nemotron-super-49b`, `llama-3.1-70b`, `llama-4-maverick`, `gemma-4-31b` | Запас; больше AI-tell |
| D | `llama-3.1-8b`, `mistral-7b` | Аварийный минимум |

Почему раньше «долго»: без таймаута Qwen/DeepSeek могли висеть 45–180 с на *каждый* кусок; failover шёл заново с первой модели. Сейчас: timeout → cooldown 90 с → сразу Mistral/Llama.

- `LLM_PROVIDER=auto` — NVIDIA → Groq → OpenRouter → Gemini.
- `LLM_PROVIDER=nvidia` — только NVIDIA-цепочка.
- `GEMINI_REQUEST_TIMEOUT_MS=45000` — обрыв «зависшего» Gemini и failover.
- Статус (цепочка + cooled models): `GET http://localhost:3000/api/llm/status`
- Глава 6: `npx tsx scripts/app-generate-chapter6.ts`
- **Канон «Лабиринт. Путь домой»** вшит в приложение (`src/data/labyrinthCanon.ts`): библия, план, worldRules, тексты гл. 5–6. При старте merge восстанавливает слоты 1–9 по порядку, перезаписывает content 5–6. Маркер: `CANON_V5_RINGS_CH6`. В оглавлении: ↺ канон, ✏ стереть все тексты, у каждой главы ✏ (текст) и 🗑 (слот).
- **Паттерны Yandex-нейродетектора** вшиты в `server/humanStyle.ts` (`YANDEX_DETECTOR_STYLE` → `humanStyleDirectives`): не телеграф без «я»; дневник + умеренное «я»; один проход сцены; без «Начну снова» / часов-штампов. Генерация глав и rewrite_detector_segments получают эти правила автоматически.

3. Запуск в режиме разработки:

```bash
npm run dev
```

Приложение откроется на http://localhost:3000

## Продакшен-сборка (по желанию)

```bash
npm run build          # соберёт клиент и сервер в dist/
set NODE_ENV=production && npm start   # Windows
```

## Полезные команды

- `npm test` — тесты (26 шт.)
- `npm run lint` — проверка типов
- `npx tsx scripts/ai-tell-score.ts файл.txt` — локальная оценка текста на генеративные признаки
- `npx tsx scripts/check-detector-reports.ts отчёт.json` — проверка отчётов Яндекс-нейродетектора

## Примечание про имя папки

Оригинальная папка называлась `writer's-studio` — апостроф в пути ломал часть
node-инструментов. Эта копия названа `writers-studio-src`; сохраняйте имя без
апострофов, кириллица в родительском пути допустима.
