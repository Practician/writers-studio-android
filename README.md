# Writers Studio Android

Автономная Android-версия Writers Studio. React-интерфейс собирается внутрь APK через Capacitor; собственный Node/Express-сервер для работы приложения не нужен.

## Как это работает

После установки пользователь выбирает ИИ-провайдера и вставляет **свой** API-ключ. Приложение обращается по HTTPS напрямую к Gemini, OpenRouter, Groq или NVIDIA. Книги, лор, персонажи, главы и паспорт автора остаются на устройстве.

| Находится в APK | Не входит в APK |
|---|---|
| Редактор, библиотека книги, Муза, генерация и редактура, локальный агент, prompt logic | Пользовательские API-ключи, Node/Express API, ключи из `.env` |

API-ключи хранятся в Android secure storage. Они не попадают в Git, GitHub Actions, release artifact или исходный код. Для OpenRouter рекомендуется создать отдельный ключ с лимитом расходов.

## Редакторский агент

Агент — не второй генератор. Он встроен в **Текст → Проверить → Передать главу редакторскому агенту** и выполняет один глубокий маршрут:

> Контекст книги → диагностика главы → бережная правка → финальный аудит → редакторское письмо.

Агент не пишет с нуля, не заменяет рукопись автоматически и не дублирует действия «Написать», «Продолжить» или точечную «Редактировать».

## Локальная разработка

```bash
npm ci
npm run dev
```

`npm run dev` запускает автономный режим: обращения приложения к `/api/*` обрабатываются встроенным direct LLM client, а не Express.

```bash
npm run lint
npm test
npm run build
npx cap sync android
```

Для открытия native проекта в Android Studio:

```bash
npx cap open android
```

## GitHub Actions

После каждого push в `master` или `main` workflow `.github/workflows/android-apk.yml` выполняет проверку типов, тесты, Vite build, Capacitor sync и создаёт debug APK. После успешной сборки APK автоматически прикрепляется к новому prerelease во вкладке **Releases**; копия также остаётся в **Actions → Artifacts** на 14 дней.

Для подписанного production APK/AAB нужен отдельный signing workflow. В GitHub Secrets при этом хранятся только keystore и пароли подписи; пользовательские LLM API-ключи туда не добавляются.
